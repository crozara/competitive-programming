# 🏆 Competitive Programming Archive

Este repositório é o meu acervo pessoal de soluções para problemas de programação competitiva. Ele atua tanto como um registro do meu treinamento e evolução algorítmica, quanto como material de apoio prático para aulas, treinamentos e oficinas de maratona de programação.

## 📂 Estrutura do Repositório

Os códigos estão organizados por plataforma e nível de dificuldade, projetados para facilitar a navegação e o estudo contínuo:

* **`/codeforces`**: Soluções da plataforma Codeforces. Atualmente categorizadas por faixas de *rating* (como `800-1200/`), mapeando a progressão natural de dificuldade — desde fundamentos lógicos e matemática básica até estruturas de dados mais complexas.
* **`/cses`**: Soluções do CSES Problem Set, organizadas diretamente pelos capítulos oficiais da plataforma.

## 🛠️ Tecnologias e Padrões

* **Linguagem:** Majoritariamente **C++**.
* **Documentação:** Cada solução (arquivo `.cpp`) contém um cabeçalho padronizado com o nome da questão e o link direto para o enunciado original, facilitando a consulta rápida.

##  Consultas e Estudos

Se você está estudando para competições de programação, sinta-se à vontade para explorar os códigos. A divisão por *rating* é um excelente guia para identificar quais tópicos treinar de acordo com o seu nível atual.
